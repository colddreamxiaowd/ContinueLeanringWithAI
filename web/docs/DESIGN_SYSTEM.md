# DESIGN_SYSTEM · V0.2 批准方向在 V1 的映射

## 视觉语言

- 风格：Linear 的状态与信息结构，Obsidian 的知识组织，Brilliant 的渐进学习与练习；不复制任何品牌界面。
- 主题：浅色为默认，深色通过根元素 `data-theme=dark` 切换。
- 主强调色：浅色 `#4b63ea`，深色 `#8d9bff`，由 CSS token 控制。
- 圆角：主要卡片 16px，按钮约 9–10px，视觉阴影轻量且低对比。
- 边框与背景：使用 `--border`, `--surface`, `--surface-soft`, `--page` 等语义变量。
- 中文主要用系统无衬线，代码用系统等宽，不引入外部字体资源以避免离线/隐私问题。

## 页面布局

1. Dashboard：项目进度视图、课程入口优先；所有不能验证的统计为 0/待连接。
2. Reader：左侧章节、中央可读文本、右侧目录与来源，窄屏折叠为单列。
3. Lab：V1 为明确的开发计划页；V3 后才允许展示可执行、单步控制等功能。

## 交互和无障碍

- 键盘焦点明显，具备跳转正文链接，按钮有 aria-label，标题逐级设置。
- 支持 `prefers-reduced-motion`，避免连续大量动画。
- 移动端抽屉点击遮罩关闭；<780px 调整为单列布局。
- 内容来源状态是产品信息，不用于视觉装饰；不得伪造同步成功。

V1 尚未完成形式化 WCAG 审计，视觉对比度仅通过浏览器人工审查预览，后续需用自动化辅助测试。
