## 指标语义（对 CoursePack 数据映射最重要）

- `progressPercent`（0–100）= 调用方计算的**学习活动完成度**，可能含章内阅读、练习、checkpoint；不能从 3/5 章节直接推断为 60%。
- `chapters[].status === "completed"` = **完成章节数**唯一事实来源。5 章中 3 章完成时显示 `3 / 5 章节已完成`。
- **查看证书**只在章节全完成且学习任务进度 100% 时出现；仅完成全部章节但活动未满则清楚显示待补项。
- 百分比和章节数量来自调用方两份不同粒度数据，必须用明确的来源事实映射，不能用示例 68% 冒充用户进度。
- SourceFileCard 的 `kind`（格式）、`syncState`（同步）和 `outcome`（生成成果）是三个不同维度；同步未完成优先显示同步状态。
- StudyTaskCard 的 `kind`（课程学习 / 动手练习 / 测验）与 `status` 独立；Demo 仅触发 callback / 本地状态变化，不写入 CoursePack。

## 执行截图与浏览器验证（整合者 / Next.js 运行环境）

启动后在 **1440×900、768×1024、390×844** 三个视口分别：
1. 截取 02 / 03 / 04 每个完整卡片及侧边变体；检查页面没有水平滚动，尤其超长文件名。
2. 切换 minimal / balanced / normal 三种模式；确保 **课程信息、进度值与 task id 不变**。
3. 键盘 Tab 到章节、文件、重试与任务；Enter/Space 回调触发一次，蓝色 focus ring 清晰。
4. 点击已完成章节只进入“复习”事件不更改完成数；点击未解锁章节不执行。点击“继续学习”，动作来自父级回调。
5. 点击失败文件“重试同步”，显示进度 0%→20%→…→100% 再显示已同步；无法用结果 badge 代替失败或未同步。
6. 点击未开始任务转进行中，再点击 Demo 的“标记完成”按钮，保留图标类型，更新右侧完成勾。
7. 在深浅背景、低动态设置下观察描边、影子与文本对比；独立检查 compact 正常/空态/完成态。
